# Habiterate 

### Product Overview
Habiterate is a lightweight, client-side web application built to rethink how we track personal goals. Traditional habit trackers rely on an all-or-nothing streak system that actively punishes users for taking a day off, turning a tool for growth into a source of guilt and anxiety.

Habiterate applies the principles of agile methodology to human behavior. It is built on the philosophy that missing a day isn't a failure; it’s just a data point to calibrate tomorrow's iteration.

### Core Product Mechanics:
Rolling Consistency over Streaks: Replaces the anxiety-inducing "Streak: 0" with a forgiving 30-day rolling percentage, visualizing long-term trends rather than short-term gaps.

The "Rule of Three" Constraint: Actively prevents user overwhelm by capping the dashboard at three concurrent habits. Users must "graduate" a habit before adding a new one.

Frictionless "Partial Wins": Allows users to log varied effort levels (e.g., Skipped, Tried, Crushed It) to accurately capture progress on low-energy days.

Morning Intent View: A focused, distraction-free daily UI that prompts the user to select just one primary focus for the day before revealing broader metrics.
